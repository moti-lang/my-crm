# סבב — מעקב לידים בשטח

מערכת אישית לניהול מכירות שטח **בהליכה רגלית באזורי תעשייה ומסחר**. משתמש יחיד, עברית מלאה (RTL), עובדת מהמחשב ומהסלולר (PWA).

ההבדל מ-CRM רגיל: **המיקום הוא הציר המרכזי, לא איש הקשר**. ליד בלי שם ובלי טלפון הוא ליד לגיטימי — הוא מנוהל במסלול "כניסה פיזית".

## מה יש כאן

| מסך | מה הוא עושה |
|---|---|
| **היום** (`/`) | באיחור / היום / השבוע. החלקה ימינה = בוצע (ואז "מה התוצאה?" → נוצר מגע ומוצע תאריך הבא), החלקה שמאלה = דחייה. |
| **סבב שטח** (`/route`) | בורר אזור + "אני כאן עכשיו" (GPS, רדיוס). קבוצות: מחכים לי / קרובים / כל השאר. כל כרטיס: מתי הייתי, מה הבטיחו, **מה ראיתי**, ניווט (Waze/מפות), "ראיתי שסגור". |
| **בנה לי סבב** (`/route/plan`) | אזור + טווח תאריכים + כמה שעות → רשימת עצירות מקובצת לסבב בוקר (תעשייה) / אחה״צ (קמעונאות), לפי רחוב, עם משפט פתיחה מוצע. |
| **הוספה מהירה** (`+`) | טקסט חופשי (או הכתבה קולית) → פירוק ל-JSON עם Claude (Sonnet) או מפרש מקומי → **טופס לאישור ועריכה** → שמירה. עובד גם אופליין (נשמר במכשיר ומסתנכרן). |
| **כרטיס ליד** | עריכה במקום של כל שדה (לחיצה = שדה קלט, יציאה = שמירה, שמירה אוטומטית עם אינדיקציה; בכשל הערך נשאר), המעקב הבא נערך ישירות (מסנכרן את המשימה, בדיקת שבת/חג, שינוי ידני מבטל "משוער"), הוספה/עריכה/מחיקה של מגעים, פס פעולות (התקשר · וואטסאפ · ניווט · הוסף מגע · ראיתי שסגור), תמונות, מחיקת ליד מתפריט ⋯. עריכות אופליין נכנסות לתור הסנכרון. |
| **לידים** | טבלה (דסקטופ) / כרטיסים (מובייל), סינון לפי אזור, סטטוס, חום, תחום, יש/אין טלפון, תאריך מעקב, תקועים; חיפוש חופשי; ייצוא CSV. |
| **יומן** | חודש + שבוע, גרירה = שינוי תאריך, משימות חופשיות, ימים מיוחדים (חג/ערב חג/חול המועד). ייצוא ICS להרשמה מיומן הטלפון. |
| **דוחות** | סיכום יום, סיכום שבוע, תקועים (30+ יום), לפי אזור (המרה). |
| **הגדרות** | התקנה למסך הבית (הוראות iOS), Web Push, קישור ICS, ייצוא/גיבוי, הרצת עבודות רקע ידנית, מצב כהה. |

**מנוע תאריכים עברי** (`src/lib/hebrew-dates.ts`): "אחרי החג", "אחרי סוכות", "אחרי החגים", "בין כיפור לסוכות", "למחרת החג", "בעוד שבוע/חודש", "ביום חמישי", "24.9"… → תאריך קונקרטי, סימון `isApproximate` (קו מקווקו), והתרעה על שבת/חג/ערב חג/חול המועד עם הצעת תאריך חלופי. לוח ישראל (`@hebcal/core`).

**אוטומציות** (`src/lib/cron.ts`, נקודת כניסה אחת `/api/cron/tick` כל 15 דקות, לפי שעון ישראל):
- 07:30 דיגסט בוקר (Push + וואטסאפ) · כל 15 דק׳ תזכורות למשימות עם `remindMinutesBefore` · 20:00 סיכום יום · ראשון 06:00 סיכום שבועי + תקועים · snapshot יומי.
- ליד ב"מחכה להם" שעבר תאריכו + 2 ימים → נוצרת משימת כניסה. חוזה מעל 7 ימים → תזכורת יומית. `nextActionAt` של ליד ומשימת המעקב שלו מסונכרנים תמיד.

**חסימת התראות בשבת ובחג** (`src/lib/notify-gate.ts`): בשבת, יום טוב, ערב שבת, ערב יום טוב וחול המועד (הגדרה, ברירת מחדל: חסום) לא נשלחת אף התראה בשום ערוץ. החסימה לפי תאריך בשעון ישראל (הערב חסום כל היום), לוח ארץ ישראל. כל שולח עובר דרך `canNotifyAt()`; מה שנחסם נשמר ונכנס לדיגסט הבוקר הראשון שאחרי, מקובץ לפי ליד, ומסומן כנשלח רק אחרי שהדיגסט יצא בהצלחה באחד הערוצים (בכשל — ניסיון חוזר ב-tick הבא). ביומן ה-ICS אין התראות בימים חסומים, ואוטומציות לא יוצרות משימות על ימים חסומים. חול המועד מדולג גם בקביעת תאריכים.

## סטאק

Next.js 15 (App Router) · TypeScript · Prisma 6 + PostgreSQL · Tailwind v4 · PWA (manifest + service worker) · Web Push (VAPID) · `@hebcal/core` · `@anthropic-ai/sdk` · Vitest.

## הרצה מקומית

```bash
npm install
cp .env.example .env        # ולמלא DATABASE_URL, APP_PASSWORD, AUTH_SECRET
npx prisma migrate dev      # יוצר את הטבלאות
npx prisma db seed          # (אופציונלי) נתוני דוגמה
npm run dev                 # http://localhost:3000
```

בדיקות יחידה (מנוע התאריכים, טלפונים, אזור זמן): `npm test`. בנייה: `npm run build`.

## משתני סביבה

| משתנה | חובה | הסבר |

| `APP_PASSWORD` | ✔ | סיסמת הכניסה (משתמש יחיד). |

| `CRON_SECRET` | ✔ | Vercel שולח `Authorization: Bearer <CRON_SECRET>`. אפשר גם `?secret=` לבדיקות. |
| `APP_URL` | ✔ | כתובת האתר (לקישורים בהתראות וב-ICS). |
| `ANTHROPIC_API_KEY` | | פירוק טקסט חופשי עם Claude. בלי מפתח — מפרש מקומי בסיסי. `CLAUDE_MODEL` (ברירת מחדל `claude-sonnet-5`). |

## פריסה ל-Vercel (כ-5 דקות, בחינם)

1. **חשבון**: [vercel.com](https://vercel.com) → Sign up with GitHub.
2. **Add New → Project → Import** את הריפו `moti-lang/my-crm` (ענף `main`).
3. **Environment Variables**: הדביקו את בלוק המשתנים (`APP_PASSWORD`, `AUTH_SECRET`, `CRON_SECRET`, `VAPID_*` — אפשר להדביק קובץ `.env` שלם לתוך שדה ה-Key והוא מתפצל לבד). לחצו **Deploy**. הבנייה הראשונה מדלגת על המיגרציות כי עדיין אין מסד נתונים — זה תקין.
4. **מסד נתונים**: בפרויקט → **Storage → Create Database → Neon (Postgres)** → Connect to project. זה מוסיף `DATABASE_URL` אוטומטית (גם `POSTGRES_URL` של Supabase/Vercel Postgres מזוהה).
5. **Deployments → ⋯ → Redeploy**. הפעם המיגרציות רצות והאתר חי בכתובת `https://<project>.vercel.app`.
6. **בטלפון**: פתחו את הכתובת → שיתוף → "הוסף למסך הבית" → הגדרות → "הפעל התראות במכשיר הזה".

`APP_URL` לא חובה ב-Vercel — הכתובת מזוהה לבד. אם משתמשים בדומיין משלכם, הגדירו `APP_URL`.

### Cron

`vercel.json` מגדיר שתי ריצות יומיות (מתאים לתוכנית Hobby החינמית): 05:30 UTC (דיגסט בוקר 07:30 בחורף / 08:30 בקיץ, אוטומציות, snapshot, סיכום שבועי בראשון) ו-17:30 UTC (סיכום יום). ה-tick מחליט לפי שעון ישראל מה להריץ ולא ירוץ פעמיים.

לתזכורות בזמן אמת (משימות עם התראה לפני) צריך ריצה כל 15 דקות: או Vercel Pro (`*/15 * * * *` ב-`vercel.json`), או שירות חינמי כמו [cron-job.org](https://cron-job.org) שקורא כל 15 דקות ל-`https://<app>/api/cron/tick?secret=<CRON_SECRET>`.

### אופציונלי

- **Claude** לפירוק טקסט חופשי: `ANTHROPIC_API_KEY` (מפתח מ-console.anthropic.com). בלי — מפרש מקומי.
- **וואטסאפ**: חשבון ב-[green-api.com](https://green-api.com) → `GREEN_API_ID_INSTANCE`, `GREEN_API_TOKEN`, `WHATSAPP_TO`.

### התראות בסלולר (iOS)

ב-iOS התראות Web Push עובדות **רק אם האפליקציה מותקנת למסך הבית** (Safari → שיתוף → הוסף למסך הבית), ורק מ-iOS 16.4. מסך ההגדרות מציג הוראות ומאפשר להפעיל את ההתראות במכשיר. באנדרואיד עובד ישירות מכרום.

מומלץ להפעיל גם את ערוץ הוואטסאפ (Green API) — זה הערוץ שבפועל ייקרא.

### יומן הטלפון (ICS)

בהגדרות → יומן (ICS): העתיקו את הכתובת והירשמו אליה מהיומן (iPhone: הגדרות → יומן → חשבונות → הוסף יומן מנוי). כל משימה מופיעה כאירוע עם התראה; תאריכים משוערים מסומנים ≈.

## גיבוי

- snapshot יומי אוטומטי בטבלת `Snapshot` (30 אחרונים), הורדה מההגדרות.
- ייצוא CSV (אקסל, UTF-8 עם BOM) וייצוא JSON מלא בכל רגע.
- בנוסף מומלץ להפעיל את הגיבוי המנוהל של Neon/Supabase.
